# Caderno Veterinário

Web app pessoal, mobile-first, para registo e organização de aprendizagem veterinária.

## V0
Protótipo visual com dados fictícios. A V1 será ligada ao Supabase depois da validação da UI/UX.

- Capturar primeiro, organizar depois.
- Contexto da escala é sugerido, nunca imposto.
- Coerência visual com a app OneVet Minha Escala.
- Dados reais: Supabase como fonte única de verdade, sem cache persistente de dados.
